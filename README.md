# some45bucks.github.io

Portfolio site for Jacob Haight. Plain static HTML/CSS/JS with no build step, served by GitHub Pages.

- `index.html` — home page: intro, grid of selected work, other projects, experience
- `work/*.html` — one page per project (IROS 2025, thesis, Strawberry Robotics, IRC 2024)
- `style.css` — colors, type, and layout (color tokens at the top)
- `main.js` — click-to-load YouTube embeds, autoplaying muted clips, and the Strawberry Robotics reel chapters
- `assets/img/`, `assets/media/` — web-sized images and clips

To add a project: copy one of the `work/` pages, then add a card to the grid in `index.html`.
