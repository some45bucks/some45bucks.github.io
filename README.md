# some45bucks.github.io

Portfolio site for Jacob Haight. Plain static HTML/CSS/JS with no build step, served by GitHub Pages.

- `index.html` — all page content
- `style.css` — colors, type, and layout (color tokens at the top)
- `main.js` — YouTube click-to-load and the Strawberry Robotics reel chapters
- `assets/media/` — web-compressed reel (720p, no audio), poster frame, and share image

Edit the reel chapters in `index.html` (`data-start` / `data-end` in seconds).
